# Lecteur

Application Windows personnelle qui transforme des livres scannés (PDF avec texte OCR), des captures d'écran,
du texte collé ou une page web en audio, avec le mot en cours surligné.

- Lecture par zones (profil « Bible d'étude » : texte et notes en deux pistes ; « Commentaire 2 colonnes » ; « Livre simple »).
- Correction automatique des erreurs d'OCR fréquentes et lecture au long des références bibliques.
- Voix edge-tts (fr-CA), export MP3 numérotés pour une clé USB.

Ce dépôt contient **seulement le code**. Aucun livre, PDF, image ou audio n'y est publié
(liste blanche dans `.gitignore` et verrou `outils/verrou.py` avant chaque commit).

Installation : voir `GUIDE-INSTALLATION.md`.
